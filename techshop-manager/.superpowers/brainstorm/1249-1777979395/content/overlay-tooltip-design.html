Spécifications TutorialOverlay

  • SVG plein écran (position:fixed, z-index:9998) avec SVG mask découpant une fenêtre transparente
  • Contour bleu #2E86C1 en pointillés (strokeDasharray="6 3") autour de l'élément
  • Padding 6px + borderRadius 8px autour de l'élément ciblé
  • MutationObserver pour détecter les éléments rendus après navigation
  • ResizeObserver pour recalculer au resize fenêtre
  • Retry x5 toutes les 500ms si élément introuvable
  • Scroll automatique : scrollIntoView({ behavior: 'smooth', block: 'center' })
  • Animation entrée : opacity 0→1, 200ms ease
  • Transition spotlight entre étapes : 300ms ease-in-out

Spécifications TutorialTooltip

  • Largeur 340px desktop / 280px mobile, z-index:9999
  • Positionnement 'auto' : calcul selon espace disponible (tiers écran)
  • Offset 12px entre élément et bulle + flèche SVG 10px
  • Touches clavier : → suivant · ← précédent · Esc dialog quitter
  • Focus trap pendant le tutoriel (accessibilité)
  • role="dialog" + aria-live="polite" pour la progression
  • Bouton "Terminer ✓" à la dernière étape (remplace "Suivant →")
